# Job Market Intelligence System (JMIS)

A Python-based analytical pipeline and web dashboard that analyses
live and historical job postings to show skill demand, salary trends,
and personalised career guidance.

## Project status
Phase 1 (Foundation) — in progress.

## Setup
1. Clone this repo.
2. Create a virtual environment:
   python -m venv venv
3. Activate it:
   - Windows: venv\Scripts\activate
   - Mac/Linux: source venv/bin/activate
4. Install dependencies: pip install -r requirements.txt
5. Copy .env.example to .env and fill in your keys.
6. Run the smoke test: python test_setup.py
